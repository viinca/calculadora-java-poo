# Calculadora em Java

Projeto desenvolvido durante os estudos da disciplina de Programação Orientada a Objetos, utilizando Java e a biblioteca Swing para construção da interface gráfica.

O projeto foi desenvolvido acompanhando as aulas e teve como objetivo praticar conceitos de Java, criação de interfaces gráficas, eventos e manipulação de componentes.

## Tecnologias utilizadas

- Java
- Java Swing
- IntelliJ IDEA

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Números decimais
- Limpar campo
- Deletar último caractere
